# 验收对应表

用户确认：不做注册；工具栏为新增、鼠标选择、拖动；点赞直接在贴纸内进行。实现和验收均按此约定。

| 要求 | 实现和验证 |
| --- | --- |
| 登录后操作 | Cookie 会话、服务端鉴权；错误密码、伪造与过期会话、退出撤销均有测试 |
| 当前在线成员 | 真实 WebSocket 连接按用户去重；双用户加入离开、同账号多标签页、最后标签页离开均有验证 |
| 点击画布发表 | 点击位置转换为共享画布坐标，弹窗发表；浏览器实际发布验证 |
| 富文本 | 六个格式按钮全部可操作；浏览器验证对应标签经保存后在另一个用户处出现 |
| 修改自己的内容 | 前端自己的编辑弹窗，后端校验作者；浏览器编辑并验证另一用户实时变化 |
| 拖动自己的贴纸 | 指针与键盘移动；位置独立版本，不覆盖正文；浏览器拖动及跨用户实时位置验证 |
| 他人只能阅读与点赞 | 只读弹窗没有保存入口，直接越权请求返回 403；修改与移动均有后端测试 |
| 点赞 | 用户与评论复合主键，目标状态幂等，可取消；浏览器验证跨用户计数变化 |
| 持久化与刷新 | SQLite/外部 PostgreSQL，位置、内容和点赞保存；重建应用和浏览器刷新验证 |
| 实时 | 数据库提交后广播快照；WebSocket 新建、编辑、移动、点赞事件和浏览器双用户流程验证 |
| 鲁棒性 | 加载与变更锁、独立版本冲突、重试去重、HTML 白名单、字数位置校验、心跳与重连 |
| 情绪颜色 | 本地中文规则分类，编辑后重算，卡片自动变色；典型正面、负面、中性、否定表达测试 |
| 情绪比例 | 实际评论计算，最大余数法分配整数百分比；空状态和小屏标签处理 |
| 智能整理 | 按情绪分列、按实际卡片高度排列；浏览器检查无重叠、没有写共享坐标、可还原 |
| 原型还原 | 图标与头像来自 .fig，点阵画布、窄侧栏、胶带便签、底部工具和弹窗；实际截图在 screenshots |
| 易于部署 | 单 Docker 服务、Render 免费配置、生产必须使用外部 PostgreSQL；CI 构建并启动生产镜像 |
| 基本文档 | README、部署步骤、账号说明、开发与失败修复记录、此验收表 |
| 分阶段 Git 管理 | 每个功能及修复先提交，再执行对应测试，通过后推进；交付包包含 Git 历史 bundle |
| 免费公网部署 | 尚未完成；等待 Render 与 Neon 账号授权，之后仍需对实际 HTTPS 地址重新验收 |

## 限制与实现约定

情绪分类使用本地规则，复杂语义和反讽可能误判。拖动松手时同步最终位置。智能整理是个人视图。采用单后端进程和完整快照，适合本次考核演示；多实例需要增加共享事件与在线状态存储。免费平台存在休眠和额度限制，不能保证任何时间都立即打开。
