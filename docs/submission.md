# 实时评论墙 · 交付说明

在线体验：https://comment-wall-production-357fe9fd.up.railway.app

演示账号：`demo_a`（赵欣）、`demo_b`（王美丽）。密码均为 `Wall2027!`。

建议用普通窗口和无痕窗口分别登录两个账号，以直接观察实时同步。同一浏览器普通标签页共享登录身份。

## 一分钟体验

1. A 选择底部「新增」，在画布空白处点一下，填写内容并发表。B 不刷新即可看到。
2. A 使用鼠标选择工具打开自己的贴纸修改内容；切到拖动工具移动位置。B 实时同步。
3. B 点击贴纸内爱心点赞，A 看到计数变化。B 可以查看 A 的内容，但不能编辑或移动。
4. 刷新页面，内容、位置和点赞保持；退出登录后在线列表更新。
5. 查看情绪占比，点击「智能整理」按情绪分列，再点「还原布局」恢复。

## 工程与验证

Python FastAPI + Vue 3/TypeScript，Neon PostgreSQL 持久化，WebSocket 同步。账号无注册；正文支持六种简单富文本格式。情绪优先使用配置的 API，未配置或异常时使用中文规则；当前演示未配 API，无外部模型费用。智能整理为个人视图，不改其他用户的共享位置。

源码附分阶段 Git 历史、README、部署步骤和回归脚本。已通过 27 项后端检查（含真实 PostgreSQL）、11 组完整浏览器验收、生产 Docker 构建启动及实际公网双用户同步和重启数据保留验证。

当前使用 Railway 免绑卡试用额度和 Neon 免费数据库。Railway 显示 30 天或 $5 用量，以先耗尽者为准。没有购买付费套餐；额度结束后线上服务可能停止。

源码仓库为私有，如评审未获仓库权限，请提交源码压缩包；包内 `git-history.bundle` 可以恢复完整提交历史。
