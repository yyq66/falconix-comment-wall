# 开发与验收

约定：每阶段功能实现及测试代码先提交 Git，再执行测试；失败时先修复、提交并重新测试，通过后进入下一阶段。测试结果和修复记录在本文件中保留。

阶段：

1. 工程基础与构建。
2. 登录、会话与登录界面（无注册）。
3. 评论创建、富文本编辑、持久化与作者权限。
4. 卡片位置、拖动、点赞与原型界面。
5. WebSocket 同步、在线成员、重连恢复。
6. 情绪变色、情绪统计与智能整理。
7. 完整浏览器验收、响应式与部署。

实现决策：第二个工具为鼠标选择；点赞在卡片内完成；每人每条最多一个赞且可取消，允许自赞。智能整理使用个人分类视图，不修改其他人的共享原始坐标。部署使用单进程 FastAPI，支持外部 PostgreSQL；本地允许 SQLite。
